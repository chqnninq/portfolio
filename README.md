# portfolio

Personal site for Channing Chen. Static HTML/CSS, no build step.

Site files live in [`portfolio-main/`](portfolio-main/).

| File | What it is |
| --- | --- |
| `index.html` | Home — short bio and selected work |
| `projects.html` | Project write-ups |
| `resume.html` | Resume, plus a link to `Channing_Chen_Resume.pdf` |
| `now.html` | What I'm up to right now |
| `blog.html`, `blog/` | Blog index and posts (`blog/template.html` is the starting point for a new post) |
| `gallery.html` | Photo grid (currently empty — drop images in `photos/` and uncomment the entries) |
| `contact.html` | Email and social links |
| `header.html`, `header.js` | Shared header partial; each page currently inlines its own copy |
| `styles.css` | All styling |
| `CNAME` | Custom domain for GitHub Pages |

Originally built from [Tanmay Hinge's](https://tanmayhinge.com) portfolio template, used with permission.
