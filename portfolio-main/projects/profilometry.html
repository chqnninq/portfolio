Automated Profilometry System

ExpMicroMech · 2026

I designed and built an automated profilometry system for UBC's robot-enabled Electron Microscopy Laboratory. This project was a part of my research work with the Experimental Micromechanical Characterisation Research Group under Dr. Ben Britton, funded by an NSERC Undergraduate Student Research Awaard (USRA).

The system allows the user to map surface topography and measure material removed from a sample. This design process involved modelling components in SolidWorks and programming Python-based control to ultimately integrate a confocal sensor and a precision stage into a motorized optical microscope.
